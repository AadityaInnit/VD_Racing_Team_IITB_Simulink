# Formula Student skidpad simulation

Final working Simulink model, serial parameter sweep tools and readable plots. Prepared 8 October 2026. This folder excludes debugging scripts, historical models/reports, validation checkpoints and raw simulation dumps.

## Requirements and setup

Developed with MATLAB R2026b, Simulink and Vehicle Dynamics Blockset. Additional dependencies reported by MATLAB's dependency checks may be required for the supplied MathWorks reference-model components. Parallel Computing Toolbox is not used.

Open MATLAB in this folder and run:

```matlab
setup_skidpad
[out,metrics] = run_baseline;       % Complete course; output remains in workspace
[out,metrics] = run_baseline(true); % Also replace the two baseline PDFs
```

Use these entry points when running on another computer. They override the model's original laptop-specific tire-file reference with the bundled `tires/` file. The .slx retains that original reference; opening it and pressing Run directly is not the portable workflow.

`parameter_sweep_simulink.m` selects the parameter, range and sweep options. `parameter_catalog.csv` is regenerated by setup from the actual model; Candidate means exposed for tuning, not physically validated. The sweep rejects unfinished/nonfinite runs and can check stationary initialization.

```matlab
compare_skidpad_suspension % Fresh baseline + four one-parameter extreme cases
```

New simulation results go into ignored `results/` folders. MATLAB build caches are directed to the system temporary directory. The supplied PDFs in `plots/` remain the curated final reports.

## Model baseline

- 6DOF vehicle body; simplified double-wishbone spring/damper suspension.
- Fixed motor-to-wheel reduction 11.5:1; constant drive command, no scheduled shifting.
- Body mass 330 kg; CG height parameter 0.30 m.
- Suspension wheel-interface stiffness 35,000 N/m and damping 2,500 N·s/m.
- Wheel vertical mass 9.3 kg per wheel.
- Tire unloaded outer diameter 16 inches: unloaded radius 0.2032 m.
- Wheel rim diameter 10 inches: rim radius 0.1270 m. Both the model and bundled tire file use these dimensions.

The current baseline completed with lap times 6.470, 5.800, 5.970 and 5.750 seconds. Scoring is the mean of laps 2 and 4: 5.775 seconds. All recorded baseline signals were finite.

## Final reports

- `plots/simple_signal_plots.pdf`: focused body and four-wheel tuning signals with named legends and startup views.
- `plots/all_signal_plots_plain_language.pdf`: every recorded baseline signal, with source-to-title/page mapping in its CSV index.
- `plots/suspension_comparison.pdf`: baseline and separate 0.1x/10x stiffness and damping experiments; includes individual-wheel plots and completed-case views.
- `plots/suspension_comparison_summary.csv`: comparison parameters, valid lap times and peak metrics. The 0.1x stiffness case became unstable and did not finish; its lap times are invalid.

## Limits relevant to physical tuning

Working means the baseline completes and the code executes; the vehicle has not been validated against real-car measurements. Some startup rollback remains. Mass partition and tire calibration still need physical validation; the 16-inch unloaded tire diameter and 10-inch rim diameter are confirmed inputs. The simplified suspension has no UBJ/LBJ hardpoint solver, explicit roll-centre inputs, linkage motion ratio, KPI/scrub/mechanical-trail model or steering torque feedback. Tire aligning moment is not handwheel torque.

Suspension experiments keep preload and initial conditions fixed and perform no retrimming. Their transient changes include settling from baseline initial conditions. High stiffness's faster lap time does not establish an optimum.

The supplied model originates from the MathWorks skidpad reference example and retains its embedded notices. No new software license is assigned by this package.
